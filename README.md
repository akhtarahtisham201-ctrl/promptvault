# PromptVault

A mobile-friendly, installable static web app for browsing, searching, favoriting, viewing and copying AI image prompts.

## Included
- 300 prompt entries: 150 Boys/Men, 60 Girls/Women, 60 Couples, 30 Baby
- Search and category filters
- Favorites saved in the browser
- Copy prompt and view prompt actions
- 45 distinct image thumbnails cropped from the approved PromptVault visual concept
- PWA manifest and service worker starter

## Publish with GitHub Pages
1. Upload all files and the `assets` folder to the root of your public `promptvault` repository.
2. Open repository Settings → Pages.
3. Under Build and deployment, select Deploy from a branch, choose `main` and `/(root)`, then Save.
4. Wait for the published URL shown on the Pages settings screen.
5. Open the URL in Chrome and choose Install app / Add to Home screen.

Note: This starter has 300 prompt entries and 45 distinct supplied image thumbnails. The thumbnails are reused across prompt entries; this package does not contain 300 separately generated original photos. Login/signup and a real paid PRO system are not included in this static version.
